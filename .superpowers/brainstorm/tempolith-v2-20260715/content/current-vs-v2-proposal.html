What changes, what stays

V2 does not abandon the existing analytical depth. It reorganizes that depth around persistent decisions and recurring forecast cycles.

Recommended sequencing

Build the workflow before the automation

This sequencing protects V2 from becoming too large. Each release has one coherent user outcome.

Recommended V2.0

The Forecast Project

A complete manual forecast cycle that can be saved, reopened, audited, and rerun.

  • Project schema and project library
  • Five-stage Forecast Studio
  • Reversible preparation recipe
  • Rolling model selection
  • Validated ensemble
  • Known-future factor planning
  • Run manifest and export package
V2.1

Portfolio Planning

Make Tempolith useful for recurring business forecasts across products, regions, or channels.

  • Batch multi-series forecasting
  • Hierarchy builder
  • Reconciled totals and intervals
  • Portfolio exception center
  • Scenario comparison by level
  • Intermittent-demand mode
V2.2

Forecast Operations

Close the loop after forecasts are issued and reduce the work needed for each new cycle.

  • Actuals import and matching
  • Bias, coverage, and drift tracking
  • Champion and challenger review
  • Local refresh schedules
  • Threshold and staleness alerts
  • Advanced fine-tuning lab

The proposed V2.0 boundary

A user can create a forecast project, validate it, publish a scenario-backed forecast, close the app, and later reproduce the exact result.

Workflow first

Conceptual interface only. No production code or product behavior has been changed.
